# NSPanel Steezy customizations

The fork's blueprint hides HVAC mode buttons and the preset picker on the climate
details page for Home Assistant climate entities. Temperature controls remain
available when the entity supports them. The embedded thermostat's preset picker
is managed by ESPHome and is not affected by this customization.

The blueprint's update source points to the `latest` tag in NSPanel-Steezy.
The tag must exist before using Home Assistant's blueprint update function.
